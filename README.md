# EasyNVR 智能视频监控平台  

## 产品定位与核心价值  
EasyNVR是NVR的超集，既可以接入各种摄像机当NVR来用，又可以批量管理多个NVR设备。EasyNVR不仅能汇聚和管理多个NVR，进行实时视频和录像视频的查看，还能够对NVR设备状态和工作状态进行实时的监测和预警，监测内容包括摄像机离线、录像缺失、画面遮挡、信号丢失等等。不仅如此，高算力版的EasyNVR还具备AI智能分析功能，分析画面中的烟火、入侵、消防器材、消防通道等等。

## 核心功能模块  

### 1. **多协议设备接入与管理**  

- **广泛兼容性**：支持 RTSP、RTMP、ONVIF、GB/T 28181 等主流协议，可接入海康、大华等品牌 IPC（网络摄像机）、NVR（网络硬盘录像机）、无人机、执法记录仪等设备，实现多品牌统一管理。  
- **灵活部署模式**：支持硬件终端（如智能云终端）与软件平台两种形态，具备低功耗、7×24 小时稳定运行能力，适用于本地服务器、私有云及边缘节点。

### 2. **全流程视频处理**  

- **实时监控与多画面预览**：提供高清视频流直播，支持 1/4/9 分屏布局，用户可远程查看实时画面并控制云台（方向调整、焦距缩放等）。  
- **智能录像与回放**：  
  - 支持计划录像、报警联动录像（如移动侦测触发），录像文件存储于本地硬盘或云端；  
  - 提供时间轴检索、倍速播放、画面暂停等回放功能，便于事后追溯。
- **视频流多端分发**：转码输出 RTMP/FLV/HLS/WebRTC 格式，兼容 PC、手机、微信 H5 等终端无插件播放。 

### 3. **智能分析与预警** 
 
- **AI 算法集成**：内置边缘计算能力，支持烟火识别、区域入侵、人脸检测、行为分析（如人员徘徊）等智能算法，实时分析视频内容。  
- **多级报警机制**：异常事件（如设备离线、画面遮挡）触发即时告警，通过语音、短信、微信、邮件推送信息，并自动保存关联录像片段。

### 4. **开放生态与扩展能力**  

- **平台级联与整合**：支持跨平台级联（如对接省级监控平台），实现多级视频资源共享与监管协同。
- **API 与第三方集成**：提供开放 API 和 SDK，便于与 ERP、智慧楼宇系统等第三方平台对接，支持定制化开发。

## 核心竞争优势  
1. **极简部署与低成本**  
   - 硬件终端通电联网即可运行，省去自建服务器费用；软件平台支持 Docker 快速部署，降低运维复杂度。 
2. **边缘-云协同架构**  
   - 边缘侧完成视频预处理与轻量分析，减少带宽占用；云端集中管理资源，提升响应效率。  
3. **AI 灵活扩展**  
   - 支持算法插件化集成，用户可按需加载第三方 AI 服务（如客流统计、车牌识别）。
4. **全生态覆盖**  
   - 配套移动端工具（如 EasyGBD 推流）、播放器（EasyPlayer.js），覆盖采集、传输、播放全链路。

## 总结  
EasyNVR 以**多协议兼容性**和**边缘智能**为核心，解决了传统视频监控系统在设备品牌零散、接入协议多样、高延迟、部署成本高方面的痛点。其“端-边-云”一体化设计尤其适用于需整合分散资源、实现实时预警的场景，是构建智慧城市安防体系、工业物联网平台的优选方案。
